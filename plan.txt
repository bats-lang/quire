=== PHASE 4: Backwards compatibility shim ===

Goal: Old stash_set_int/stash_get_int still work.

In bridge's stash module, keep the old API but route through the typed state:

  (* for backwards compat — will be removed when callers migrate *)
  implement stash_set_int(slot, v) =
    if slot = 11 then set_file_size(pos_of_int(v))
    else if slot = 12 then set_cd_offset(nat_of_int(v))
    ...

  implement stash_get_int(slot) =
    if slot = 11 then g0ofg1_int(get_file_size())
    else if slot = 12 then g0ofg1_int(get_cd_offset())
    ...

The runtime checks (pos_of_int, nat_of_int) are in the UNSAFE bridge package
where g1ofg0 is allowed. They validate on write, so reads are always correct.
